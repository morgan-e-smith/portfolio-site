Buttons start an action or move someone to the next page; there are three variants and only one primary per view.

- **primary**: `turquoise-ink` fill, white text, hovers to `ink`. Use once per screen for the main action ("View work").
- **secondary**: `paper-raised` with a `line` border, hovers to an `ink` border. Supporting actions ("Download resume").
- **text**: `turquoise-ink` underlined text for inline actions ("See all work").
- Labels are sentence case and start with a verb. No icons alone; an arrow may follow a text label.
- Focus ring: 2px `turquoise-ink`, offset 2px. Never use bright `turquoise` as a button fill: white on it fails contrast.

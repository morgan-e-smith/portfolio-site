Tags label what something is (its pillar), what state it is in (status), or which section you are in (eyebrow).

- **pillar**: pill, one color family per pillar. Only the three pillars: Strategy, Building, Enablement.
  - Strategy: `brass-tint` background (15% `brass` over `paper-raised`), `brass-ink` text.
  - Building: `turquoise-tint` background, `turquoise-ink` text.
  - Enablement: `ink` background, `paper` text.
- **status**: `brass` border, `brass-ink` text on `paper-raised`. For honest work state, like "In progress". Never hide unfinished work; tag it.
- **eyebrow**: plain uppercase `brass-ink` text above a section heading.
- Keep labels to one or two words.
